NeuroInsight

Explainable Multimodal AI System for Alzheimer’s Detection

Nov 2026
React TypeScript FastAPI PostgreSQL PyTorch Grad-CAM SHAP

GitHub Repo ↗

  • Classifies Alzheimer’s progression (CN, MCI, AD) from 3D MRI, PET and six clinical biomarkers using a dual-branch 3D ResNet-50 with CBAM and Swin window attention.
  • Explains each result with tri-planar 3D Grad-CAM overlays and SHAP biomarker importance in a React and FastAPI research portal.
  • Internal held-out split of 80 subjects from a 541-subject ADNI-derived cohort: 82.50% accuracy and 0.9246 macro ROC-AUC.
