This portfolio showcases end-to-end projects spanning **Machine Learning, Computer Vision, Agentic AI, and Full-Stack Web Development**, built with a focus on performant, accessible, and user-centered engineering.

---

## ⚡ Highlights & Features

- **Zero Heavy Frameworks:** Hand-crafted using vanilla HTML5, modern semantic CSS3, and modular ES6+ JavaScript for instant load times and zero build dependencies.
- **Visual Identity & Custom SVGs:** Bespoke SVG branding, responsive project cover illustrations, and custom badge icons.
- **Live GitHub Activity:** Dynamic client-side integration with the GitHub REST API displaying public repository count, followers, and recently updated repositories.
- **Interactive Project Filtering:** Accessible, filterable gallery (`All`, `AI & machine learning`, `Full-stack`) with live screen-reader announcements (`aria-live`).
- **Interactive Polish:** Subtle mouse spotlight effects, rotating role badges, smooth internal anchors, and mobile-friendly responsive navigation.
- **Accessibility & Contrast Focused:** Audited color contrast ratios (WCAG AA compliant), skip-to-content links, visible focus outlines, and keyboard accessibility.

## 💻 Local Development & Preview

Because this project is built entirely with vanilla web standards, you can preview it locally using any static web server:

### Option 1: Python
```bash
# In the portfolio directory
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 2: VS Code Live Server
Open the project folder in VS Code, right-click `index.html`, and choose **"Open with Live Server"**.

### Option 3: Node `serve` / `npx`
```bash
npx serve .
```
